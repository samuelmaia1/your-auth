# Package `domain.user`

## Finalidade

Agrupar entidades, serviços, políticas e regras de negócio relacionadas ao
usuário.

## Motivo

Manter todo o comportamento de domínio de usuário em um contexto claro, isolado
de detalhes de infraestrutura e da camada HTTP.

## Quando colocar arquivos aqui

- O arquivo representa dados, invariantes ou comportamentos de usuário.
- O arquivo implementa uma regra de negócio específica de usuário.
- O arquivo coordena operações de domínio que envolvem usuário.
