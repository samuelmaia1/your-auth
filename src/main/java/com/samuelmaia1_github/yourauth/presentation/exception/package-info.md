# Package `presentation.exception`

## Finalidade

Concentrar tratamento de exceptions e respostas de erro da API.

## Motivo

Padronizar como falhas de domínio, infraestrutura e validação são traduzidas para
respostas HTTP.

## Quando colocar arquivos aqui

- O arquivo implementa handlers globais ou locais de exception HTTP.
- O arquivo define modelos de erro retornados pela API.
- O arquivo mapeia exceptions internas para status e mensagens HTTP.
