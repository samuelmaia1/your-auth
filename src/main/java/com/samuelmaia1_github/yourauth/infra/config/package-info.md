# Package `infra.config`

## Finalidade

Concentrar classes de configuração da infraestrutura da aplicação.

## Motivo

Manter propriedades, configurações de frameworks e ajustes globais separados das
regras de negócio e dos endpoints HTTP.

## Quando colocar arquivos aqui

- O arquivo define configurações de bibliotecas, frameworks ou módulos técnicos.
- O arquivo mapeia propriedades externas para objetos de configuração.
- A classe tem responsabilidade de bootstrap ou setup técnico.
