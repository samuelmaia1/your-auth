# Package `infra.utils`

## Finalidade

Agrupar utilitários técnicos reutilizáveis pela infraestrutura.

## Motivo

Evitar duplicação de pequenas operações de apoio sem misturar essas funções com
regras de negócio ou contratos de apresentação.

## Quando colocar arquivos aqui

- O arquivo oferece uma função técnica pequena e reutilizável.
- O utilitário apoia infraestrutura, configuração ou integrações.
- Não existe um package mais específico para a responsabilidade.
