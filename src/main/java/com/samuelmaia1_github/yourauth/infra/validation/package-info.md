# Package `infra.validation`

## Finalidade

Concentrar validações técnicas e validadores de infraestrutura.

## Motivo

Separar validações ligadas a frameworks, formatos externos ou entradas técnicas
das regras de negócio do domínio.

## Quando colocar arquivos aqui

- O arquivo implementa validadores customizados de anotacoes ou formatos.
- O arquivo valida requisitos técnicos de infraestrutura.
- A validação depende de bibliotecas, configurações ou recursos externos.
