# Package `infra.security`

## Finalidade

Concentrar componentes de segurança da aplicação.

## Motivo

Manter autenticação, autorização, filtros e utilitários de segurança em uma área
técnica separada das regras de negócio.

## Quando colocar arquivos aqui

- O arquivo configura autenticação ou autorização.
- O arquivo implementa filtros, providers ou services de segurança.
- O arquivo lida com tokens, credenciais ou integração com Spring Security.
